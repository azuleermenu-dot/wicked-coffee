# Wicked Coffee Website

Premium mobile-first cinematic website concept for Wicked Coffee, Quezon City.

## Project
- Built with React 19 + TanStack Start + Vite
- Cinematic scroll-scrub experience
- Responsive mobile-first layout
- Wicked Coffee brand palette and content
- Online ordering, Instagram, and directions links
- Accessibility: reduced-motion support

## Source
The complete working project is maintained in the connected Higgsfield website workspace. This repository is the GitHub project mirror/backup.
